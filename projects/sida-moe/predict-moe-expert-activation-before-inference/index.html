Predicting MoE Expert Activation Before Running the Model

Can you predict which MoE experts a token will activate before running the model?

Answer

Yes, to a large degree. In SiDA-MoE (Du et al., MLSys 2024), an offline-trained predictor, which the paper calls a hash function, takes the sequence of input token embeddings and predicts, for every token and every MoE layer, which expert the token will be routed to and the scaling factor that the router would assign. With these predictions available before inference starts, the system can load the needed experts onto the GPU ahead of time.

The motivation is latency. Without prediction, expert activation patterns are only known after each router runs, and moving experts between CPU and GPU at that point breaks the forward pipeline. Because the predictor works on the input embeddings independently of the model's forward pass, it can run in a separate hash-building thread on the next batch while the inference thread processes the current one, so expert selection is removed from the inference critical path.

Predictability rests on an empirical observation: although self-attention mixes tokens before each MoE layer, a token's expert choice depends on only about 1 to 4 other tokens or positions, measured by corrupting or permuting parts of C4 inputs to Switch-base-128. The predictor is therefore a lightweight 2-layer LSTM with a SparseMax attention layer that focuses on a few critical tokens and a residual connection from the current token. It is trained on pairs of input embeddings and the true expert activations recorded from the model, using truncated knowledge distillation over the top-T router logits plus a cross-entropy term.

Measured as top-3 hash hit rate, prediction accuracy is 99.00%, 97.41% and 91.74% for Switch-base-8 on SST2, MRPC and MultiRC, and 98.78%, 98.65% and 90.49% for Switch-base-128. Accuracy is lower on the long MultiRC inputs. Using these predictions in place of the routers preserves 97.49% to 98.95% of fine-tuned task performance for Switch-base-8 and 92.56% to 93.02% for Switch-base-128.

Setup

The predictor is trained on the train split of each dataset with the true expert activation tables and evaluated on the test split. Models: Switch-base-8 and Switch-base-128 fine-tuned on SST2, MRPC (GLUE) and MultiRC (SuperGLUE). Training uses AdamW, learning rate 5e-5, batch size 64, truncation T = 30 and loss weight λ = 0.005. Top-1 predicted experts are used for SST2 and top-3 for MRPC and MultiRC.

Prediction accuracy was measured for Switch Transformers with top-1 routing (8 and 128 experts) on three GLUE/SuperGLUE tasks, with one predictor trained per dataset.
