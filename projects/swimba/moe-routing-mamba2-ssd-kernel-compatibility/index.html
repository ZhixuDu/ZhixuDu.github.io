MoE Routing Compatible With the Mamba-2 SSD Kernel

Does routing between expert projections break the state space duality kernel in Mamba-2?

Answer

It does not break it, provided the experts are mixed in parameter space and the transition is shared. In Swimba (Du et al., 2026), Theorem 1 states that if each expert e supplies streams B^(e)_t, C^(e)_t and X^(e)_t, the transition A is shared, and routing weights π_{t,e} are nonnegative over an active set K_t (dense or top-k), then defining the mixed injection U_t = Σ π_{t,e} B^(e)_t X^(e)_t and mixed readout C_t = Σ π_{t,e} C^(e)_t turns the layer into exactly a single selective SSM, h_t = A h_{t-1} + U_t and Y_t = C_t^T h_t, with state size N independent of the number of experts and of the sparsity of K_t.

Because the result is a standard selective SSM, the same SSD implementation used in Mamba-2 can evaluate it. SSD relies on the transition being a scalar times identity so that the recurrence is dual to a structured, semiseparable matrix multiplication computed in chunks. Swimba keeps A shared across experts and time, so routing only changes the streams fed into the SSM, not the SSM evaluation itself. The paper describes the proof as immediate once the recurrence is written in terms of the mixed streams.

In the Swimba layer this is realized by replacing the Mamba-2 in-projection with several expert in-projections and a router. The selected experts' outputs are aggregated when more than one is active, and the aggregated parameters go into the unchanged SSM module. The Mamba-2 block wrapper, which produces the SSM inputs in parallel at the start of the block, is preserved.

Swimba-14B, built this way on Nemotron-H-8B with 4 experts and top-1 routing, has FLOPs per token within 0.2% of the baseline and raises average benchmark accuracy from 69.47 to 70.81.

Setup

Theoretical analysis of a selective SSM h_t = A h_{t-1} + B_t X_t, Y_t = C_t^T h_t with state size N, P channels, E experts, softmax routing probabilities and a dense or top-k active set; proofs are in Appendix A of the paper. The architecture is instantiated on Mamba-2 and evaluated as Swimba-14B (4 experts, top-1) built on Nemotron-H-8B.

The structural result assumes a transition A shared across experts; designs with expert-specific transitions are outside its statement.

Source

Swimba: Switch Mamba Model Scales State Space Models. Zhixu Du, Krishna Teja Chitty-Venkata, Murali Emani, Venkatram Vishwanath, Hai (Helen) Li, Yiran Chen. Advances in Neural Information Processing Systems 39 (NeurIPS 2026), 2026. Evidence: Section 3.4 Theorem 1, Appendix A.1.
