Upcycling a Pretrained Hybrid Mamba Model Into an MoE SSM

Can you upcycle a pretrained Nemotron-H or Mamba-2 model into a mixture-of-experts SSM by training only experts and routers?

Answer

Yes. Swimba (Du et al., 2026) is built this way. The authors start from the Nemotron-H-8B checkpoint, copy all shared parameters, replace every Mamba-2 layer with a Swimba layer, and introduce new expert and router parameters for each Swimba layer. During continued training only the newly introduced expert and router parameters are updated; the copied backbone parameters stay fixed.

The architecture keeps Nemotron-H-8B's 52-layer hybrid layout. Four self-attention layers are dispersed through depth and the remaining layers alternate between sequence-mixing layers and FFN layers; the first layer is a sequence mixer, the last is an FFN, and self-attention layers precede the FFNs they pair with. The only architectural change is the sequence mixer: each Mamba-2 layer becomes a Swimba layer, in which the Mamba-2 in-projection is replaced by several expert in-projections and a token-level router, and the SSM computation itself is unchanged.

Training is supervised fine-tuning on the Llama-Nemotron Post-Training Dataset, which spans math, code, science, instruction following, chat and safety. Only the SFT portion is used, with teacher-forced training on the dataset's standard schema of role-based input chat messages and a target output string. The paper does not report learning rate, number of steps or tokens trained.

The resulting Swimba-14B has 4 experts per Swimba layer with one active per token. Against Nemotron-H-8B it raises average accuracy across nine benchmarks from 69.47 to 70.81, with MMLU going from 71.7 to 75.0, at FLOPs per token within 0.2%. In vLLM decoding it is slightly slower, with as low as a 10% slowdown.

Setup

Backbone: Nemotron-H-8B, a 52-layer hybrid decoder with four self-attention layers and alternating Mamba-2 and FFN layers. Swimba-14B replaces every Mamba-2 layer with a Swimba layer of 4 experts, top-1 routing per token. New expert and router parameters are trained with supervised fine-tuning on the SFT portion of the Llama-Nemotron Post-Training Dataset while the copied backbone is frozen. Accuracy is measured with LM-Evaluation-Harness on ARC-Challenge, ARC-Easy, BoolQ, HellaSwag, MMLU, OpenBookQA, PIQA, RTE and WinoGrande; FLOPs with the PyTorch profiler; throughput and latency with vLLM (Transformers backend) on a single 40GB A100 GPU. Baseline: Nemotron-H-8B.

The recipe was shown for one backbone (Nemotron-H-8B) with a frozen copied backbone and SFT-only data; training hyperparameters and data volume are not reported.
