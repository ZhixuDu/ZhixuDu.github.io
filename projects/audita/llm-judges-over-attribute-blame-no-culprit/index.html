LLM Judges Over-Attribute Blame When No Agent Is at Fault

Do LLM judges over-attribute blame when no agent is at fault?

Answer

In the tests reported in AUDITA (Du and Chen, 2026), yes. On 300 no-cause accidents from CulpaBench, LLM judges in all three Who&When formats (all-at-once, step-wise and binary-search) named someone in 100% of runs, under a neutral prompt that explicitly offered "NONE" as an answer. A statistical anomaly detector also manufactured a culprit in every case. The certified attribution engine manufactured a culprit in zero cases.

The control is designed to be falsifying. In a no-cause incident the adverse outcome is produced by an exogenous environmental event and no agent appears in the incident slice, so the correct output is universal exoneration. A companion trivial control has a single command with a direct path to the outcome, where the correct answer is that command's author at full responsibility; the LLM judges clear that control exactly.

The failure is one of output format as much as reasoning. A single-culprit output cannot express a shared cause or an absent one, however well the model reasons, and an anomaly detector always has a most-anomalous message, so it can never say that no one is responsible. In Audita, a message becomes a candidate only if its committed effect reached the outcome through an intact production path, and each reported cause must pass counterfactual replay. Proposition 1 states that the engine's failure mode is abstention, not false accusation.

The same tendency appears with omissions. On 74 held-out unexpected-startup incidents, where the only breach is a missing halt, LLM judges convicted an innocent agent in 67-100% of runs unless the silent duty-holder was offered as a candidate. Across the five CulpaBench structures in Table 2, judge formats averaged 0.303 to 0.343 responsibility error and the anomaly detector 0.900, against 0.000 for the certified verdict.

Setup

CulpaBench: over 1,000 incidents in a deterministic multi-robot facility simulator, with structures grounded in 42 public OSHA/NIOSH robot-accident records and ground truth computed by exact world re-execution and an analytic oracle that shares no code with the engine. Each structure is scored over 300 draws and three generation seeds. Baselines: three Who&When LLM judge formats (all-at-once, step-wise, binary-search) on Qwen2.5-72B-Instruct, CAR / CausalFlow single-site scoring, Shapley-value attribution, and a statistical anomaly detector.

Shown on simulated CulpaBench no-cause and trivial controls with Qwen2.5-72B-Instruct running the three published Who&When judge formats.
