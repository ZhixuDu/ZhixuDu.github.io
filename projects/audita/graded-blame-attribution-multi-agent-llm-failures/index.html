Graded Blame Attribution for Multi-Agent LLM Pipeline Failures

How can I attribute blame to multiple agents when an LLM multi-agent pipeline fails, instead of naming one culprit?

Answer

Instead of asking a judge to name one culprit, compute a graded responsibility degree for every agent from the recorded messages and combine it with a check of whether each agent breached a declared duty. In AUDITA (Du and Chen, 2026), each agent receives a Chockler-Halpern degree of responsibility between 0 and 1 for the adverse outcome, together with duty and breach findings, so a failure caused by two agents produces two nonzero grades instead of a single pointer.

The procedure has three steps. Every inter-agent message is signed and cites the messages it acts on. A production gate first removes messages whose committed effect never reached the outcome. The surviving candidates are graded under the modified Halpern-Pearl definition of actual causality, where a minimal cause X* with witness set W* receives rho = 1/(|X*|+|W*|), and an agent's responsibility is the strongest grade of any cause containing one of its messages. Each reported cause is then re-executed under intervention to confirm that removing it averts the failure. The grades are degrees of responsibility, not shares, so they need not sum to one.

On live GSM8K pipelines, the Who&When-style LLM judge had a responsibility error of 0.589. The full graded verdict, whose breach test may consult the correct answer, reached 0.170, and a deployable variant that never sees the answer key reached 0.159. Shapley-value attribution, the strongest baseline, reached 0.223. CAR / CausalFlow single-site counterfactual scoring reached 0.408, the same error as the method with its duty layer removed, which identifies the duty layer as the component that separates the verdict from the baselines.

The gold-free variant is not worse because the two breach tests disagree essentially only on honest errors, where a solver follows every duty and still reaches a wrong answer. Under negligence semantics such an agent is not culpable, and the ground truth agrees with the deployable test.

Setup

Live corpus: a GSM8K multi-agent pipeline with a planner, three parallel solvers, an aggregator that carries a declared normative duty, and a verifier; three independently generated corpora of 480 cases each (one development, two holdouts), with fault injection calibrated to an empirical multi-agent failure taxonomy and every label replay-verified. Models are open-weight (Qwen2.5-72B-Instruct primary, Qwen2.5-7B-Instruct and Llama-3.1-8B-Instruct for additional study), served with vLLM on NVIDIA A100-80GB GPUs with greedy decoding and three generation seeds. Baselines: the Who&When LLM judge, CAR / CausalFlow single-site counterfactual scoring, and Shapley-value attribution. Metric: responsibility error, the l1 distance between reported and true graded responsibility profiles.

Shown on GSM8K planner-solver-aggregator-verifier pipelines with open-weight models under replayable serving, scored against duty-aware Chockler-Halpern ground truth.
