Handling Preemption in Counterfactual Blame Attribution

How to handle preemption when doing counterfactual blame attribution over logs?

Answer

Separate causal production from counterfactual dependence. Before any counterfactual is computed, check whether each command's committed effect was actually realised and propagated into the state that made the outcome true, and retire commands whose effect never arrived. AUDITA (Du and Chen, 2026) calls this the production gate. Its Proposition 2 states that a message with no intact production path to the outcome receives rho = 0 and an exoneration note, regardless of its content.

The gate relies on two message fields. Each message carries an effect predicate, the world- or work-state change its author commits to, and a citation set naming the messages it acts on. A production path is a citation path from a message to the actuation of the outcome whose every link verifies and whose every committed effect is confirmed by the recorded state changes. Gated-out messages never enter the structural causal model, so they cannot appear in any cause set. This follows the legal requirement of causation-in-fact and the philosophical distinction between dependence and production.

The gate also explains why two identical transcripts can need different attributions. In the inert-twin structure of CulpaBench, the transcript is bitwise identical to the redundancy structure, but the second command's actuator was locked out. Under redundancy each command carries 1/2; under the inert twin the first carries 1 and the second carries 0, with a breach finding for a skipped review step. Every transcript-level method returns one verdict for both and is right on only one, while the certified engine separates them in all draws because the dispatcher's citations record which proposal it acted on.

In Table 2 the method scores 0.000 on preemption and the inert twin. On the inert twin, single-site scoring and Shapley attribution both err at 0.667, and the anomaly detector errs at 1.000 on both structures. The ablations identify the gate as load-bearing on exactly these two structures.

Setup

CulpaBench: over 1,000 incidents in a deterministic multi-robot facility simulator, with structures grounded in 42 public OSHA/NIOSH robot-accident records and ground truth computed by exact world re-execution and an analytic oracle that shares no code with the engine. Each structure is scored over 300 draws and three generation seeds. Baselines: three Who&When LLM judge formats (all-at-once, step-wise, binary-search) on Qwen2.5-72B-Instruct, CAR / CausalFlow single-site scoring, Shapley-value attribution, and a statistical anomaly detector.

Shown on simulated CulpaBench preemption and inert-twin structures, where the record carries authored citations and committed effect predicates.
