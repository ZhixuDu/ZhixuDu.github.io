Attributing Responsibility for Omissions Like a Missing Halt

How to attribute responsibility to an agent that failed to act, such as a missing safety halt?

Answer

Represent the action that should have happened as its own causal variable. In AUDITA (Du and Chen, 2026), duty-indexed absence variables are first-class variables in the structural causal model: when a duty registry obliges a supervisor to issue a halt within a time window and none is issued, the absence is recorded as a fact and graded like any message, rather than treated as a gap in the log.

In the omission structure, a sensor records a human entering, the supervisor is obliged to halt, no halt is issued, and the standing motion command proceeds, so the outcome is the conjunction of the motion command and the missing halt. Both are singleton but-for causes with responsibility 1, but only the supervisor receives a breach finding; the duty-compliant issuer of the motion command is causally implicated and cleared on breach. The counterfactual halt is obtained by running the certified supervisor policy offline over the recorded sensor reports.

The paper tests this out of loop on unexpected startup during maintenance, the modal fatal pattern in a published analysis of US robot fatalities: a worker is struck because the pre-entry halt was never issued, every issued command is duty-compliant, and the omission is the sole breach. With the engine, oracle and baselines frozen, on 74 held-out incidents the method was exact (0.000) and blamed the omission alone. Single-site counterfactual scoring pinned the innocent sole actor every time, and LLM judges convicted an innocent in 67-100% of runs unless the silent duty-holder was offered as a candidate.

On the core omission structure of Table 2, the certified verdict scored 0.000, LLM judges and single-site scoring 0.500, and Shapley attribution 0.667. Single-site scoring cannot see an omission because there is no message to delete.

Setup

CulpaBench: over 1,000 incidents in a deterministic multi-robot facility simulator, with structures grounded in 42 public OSHA/NIOSH robot-accident records and ground truth computed by exact world re-execution and an analytic oracle that shares no code with the engine. Each structure is scored over 300 draws and three generation seeds. Baselines: three Who&When LLM judge formats (all-at-once, step-wise, binary-search) on Qwen2.5-72B-Instruct, CAR / CausalFlow single-site scoring, Shapley-value attribution, and a statistical anomaly detector.

Shown on simulated omission and unexpected-startup incidents where the duty to act is registered in advance in a duty registry.
