Framing Attacks on Causal Responsibility of AI Agents

Can a malicious agent frame an innocent agent in a causal responsibility analysis?

Answer

Partly. AUDITA (Du and Chen, 2026) shows that an insider holding a valid key can make an innocent, duty-compliant agent a genuine but-for cause of harm, and that no record machinery can prevent this. What the insider cannot do is make that agent culpable, because a culpability finding requires a breach witnessed by the accused agent's own certified conduct (Theorem 1).

The paper builds two attacks. In conditioning (Attack I), the insider runs the policy "if the victim's message is present, emit the harmful command, citing it; otherwise behave". Every item certifies, the production gate passes through the attacker's own citation, and honest replay certifies the victim's responsibility at 1. In inevitability rigging (Attack II), the attacker deviates in a way that lies on no path from the victim to the outcome and is not itself a cause: it rigs an otherwise inevitable harm so that only the victim could have prevented it. This shows that localising every framing on a causal path is impossible.

Three results bound the damage. Theorem 1 holds for content-determined duties, which are predicates over an agent's own certified messages and inputs, with no ground-truth label or third-party assertion. Theorem 2 shows that if a coalition's deviations from a declared reference standard raise a compliant agent's involvement, those deviations are an actual cause of the victim's pivotality, and a minimal blame-shift certificate, checkable by replay, grades each framer with the same responsibility calculus. Theorem 5 extends this to every order, and Proposition 4 shows that padding with inert decoys changes no grade.

Across 600 incidents, both attacks raised victim involvement to 1.0 with every message verifying, while victim culpability stayed 0.000 and a certificate named the attacker in every incident. A level-2 scapegoat attack convicted a benign deviator in 0 of 330 draws and named the true attacker in all 330. The authors note these attacks are theorem-derived, testing the implementation rather than covering all adversaries.

Setup

Attack constructions from Supplementary Notes S3-S4 instantiated in the deterministic CulpaBench facility simulator (conditioning on a victim's compliant message, inevitability rigging via a redundant route, and a level-2 scapegoat in which a supervisor's duty-compliant halt is pivotal). Counterfactuals are decided by exact world re-execution with citation-chain propagation; certificates are computed by the same responsibility calculus over deviation selectors relative to a declared reference standard.

Guarantees hold under content-determined duty rosters, a replayable stack, a recorded channel and unstolen keys, with key holders allowed to be arbitrarily malicious; tested attacks are theorem-derived.
