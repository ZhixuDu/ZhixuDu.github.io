Teacher-Forced Agreement vs Free-Running Small-Model Generation

If a small model agrees with a large model token by token, can it safely generate several tokens on its own?

Answer

Not reliably beyond a few tokens. Du et al. (2026) let a smaller Qwen2.5 model generate up to L tokens from the verified reference midpoint and then hand the combined text back to Qwen2.5-72B. Relative to an uninterrupted 72B continuation, the 0.5B model's accuracy difference was -0.09 points at one token, -0.86 at 8, -2.19 at 16, -4.53 at 32 and -9.44 at 64. Larger models degrade less: at 64 tokens the losses are 4.68 points for 1.5B and 1.50 points for 7B.

The reason is the difference between teacher forcing and generation. The sufficient-compute map measures whether a model reproduces a token when given the correct prefix. Once a small model's prediction is used, it changes the prefix that later predictions condition on, so the effect includes deviations, alternative solution paths and recovery. Scheduled sampling and exposure-bias research address the same distinction.

The reference map is a weak guide to who can safely take over. Across 1,758 items, the fraction of suffix words assigned to the 14B rung or higher has a Spearman correlation of only 0.195 with the 0.5B model's midpoint accuracy loss. The paper therefore argues for choosing model capacity and delegation length jointly.

Protocol: the 1,758 core problems with verified references from both generators; both arms start from the same Qwen-written prefix and receive no further reference tokens; 16 completions per condition, paired by problem; 590,688 small-model completion conditions in total. Memorization screening barely changes the results, moving the pooled 0.5B handover difference at a quarter of the reference from -0.504 to -0.500.

Setup

The 1,758 core problems with verified references from both generators (1,275 GSM8K, 347 MATH-500, 136 HumanEval). A smaller Qwen2.5 model and the Qwen2.5-72B control start from the same Qwen-written prefix; 16 completions per condition at temperature 0.7, top-p 0.95, paired by problem. The length sweep uses 0.5B, 1.5B and 7B with L in {1, 2, 4, 8, 16, 32, 64} from the reference midpoint; full-suffix handovers add 32B and vary the start fraction over {0, 0.25, 0.5, 0.75, 0.9}.

Shown for Qwen2.5 models handing back to Qwen2.5-72B on GSM8K, MATH-500 and HumanEval with sampled decoding.
